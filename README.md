# 연무 · 20F FIRE ESCAPE — playable prototype v0.4

세로 화면용 1인칭 3D 화재 생존 게임. **공식 소방 교육·화재 공학·실제 건물 대피를 검증한 시뮬레이터가 아니다.** 수치와 도구 상호작용은 허구의 게임 규칙이다.

## 실행

압축을 풀고 `fire-escape` 폴더 안에서:

```sh
python -m http.server 4173
```

브라우저에서 `http://localhost:4173`에 접속한다. ES 모듈을 사용하므로 index.html을 파일로 더블클릭해서 실행하지 않는다. Three.js·VRM 런타임·모델·재질이 동봉되어 외부 CDN 없이 실행된다. 최초 모델 로딩이 끝나야 시작 버튼이 활성화된다.

## 조작

- 모바일: 왼손 스틱 이동, 스틱 바깥쪽까지 밀면 달리기. 오른쪽 화면 드래그로 시점.
- PC: WASD 이동, Shift 달리기, 좌/우 방향키 회전, E 확인/작업 중단, C 낮은 자세, I 소지품, H 위치 알림, Esc 일시 정지.
- 문·거울·용품 가까이에서 초록색 확인 버튼을 누른다. 장비 버튼은 소지품과 소화기·보호 장비 사용 패널이다.
- 낮은 자세에서는 달릴 수 없다. 계단은 한 번에 한 층, 약 0.9초 전환이지만 경로 노출 비용은 남는다.
- 핀치/더블탭 확대를 막고, 앱을 벗어나면 자동 일시 정지한다.

## 캐릭터·거울

- 매 판 남/여 표기와 외형을 무작위 선택한다. 체력·호흡·이동 속도·도구 성공률에는 성별 차이가 없다.
- 현재는 **같은 pixiv 애니메이션풍 VRM 베이스를 개조한 두 외형**이다. 남성 변형은 짧은 머리·블루 계열, 여성 변형은 긴 머리·핑크 계열이며, 완전히 별도 제작한 남/여 모델은 아니다.
- 단일 스킨드 전신과 절차적 걷기·달리기·낮은 자세를 사용한다. VRM aim/roll 제약을 갱신해 옷 소매가 T자 자세로 남는 문제를 수정했다.
- 1인칭에는 머리·얼굴과 카메라에 너무 가까운 칼라/상체 일부를 표시하지 않는다. 아래를 보면 손·하체·신발이 보인다. 거울에는 같은 외형의 온전한 전신이 비친다.
- 거울은 실시간 반사다. 고급 모션캡처·고품질 애니메이션 완성품은 아니며, 모델과 자세는 계속 개선할 수 있는 프로토타입이다.

## 비상용품·잠금 상호작용

- 오른쪽 복도 관리 도구함: 지렛대·망치·손전등. 손전등은 가까운 공간 조명만 보탠다. 같은 도구를 다시 주워도 내구도가 회복되지 않는다.
- 왼쪽 소화기 거치대: 층당 1회분. 장비 패널에서 사용한다.
- 왼쪽 옥내소화전: 고정 설비. 한 층당 한 번, 8초간 이동하지 않고 작업한다.
- 소화기는 4초, 도구 시도는 5초가 필요하다. 작업 중 이동은 멈추지만 연기 노출은 계속되며, 확인 버튼으로 중단할 수 있다. 중단해도 이미 소모한 자원은 환급되지 않는다.
- 잠긴 관리실·옥상 문은 여러 번 시도해야 한다. 내구도·힘·작업시간·실패 가능성이 있으며, 손상된 문틀은 도구로 끝내 열리지 않을 수도 있다. 소음이 기록되고 파손 시 잠시 분진으로 시야와 노출이 나빠진다.
- 관리실에는 시간 소모형 키 탐색 대안이 있다. 관리실을 열면 옥상 키를 얻는다. 옥상 잠금을 풀어도 직접 진입해야 하고, 즉시 승리하지 않는다. 계단 A/B 우회 경로는 잠금 작업과 독립적이다.
- 소화 설비 효과는 6초로 제한된다. 작은 화염/자극만 일시적으로 줄이는 추상적 게임 효과이며, 유독가스를 제거하지 않는다. 짙은 연기에서는 사용을 거부하고 안전 통로를 보장하지 않는다.
- 문 파손·소화기·소화전은 **실제 작업법을 재현하지 않은 타이머/상태 기반 상호작용**이다. 물리적 파괴·도구 휘두르기·실제 설비 조작 교육은 구현하지 않았다.

## 생존 분기

- 화재층은 처음에 알려주지 않는다. 문 너머의 연기와 열 단서를 확인한다.
- 1층에 도착해도 출입구를 지나야 탈출한다.
- 승강기는 정상 운행·정전·층 사이 정지·연기 유입으로 갈린다. 누를 때마다 새로 추첨하지 않는다.
- 테라스·옥상은 즉시 성공 지점이 아니다. 신고·대기·주변 연기 조건에 따라 구조 또는 실패한다.
- 마스크·수건·담요는 일시적인 게임 효과만 있다. 유독가스 노출을 없애지 않는다.
- 호흡 여유·체력·힘은 가상의 게임 수치이며 의학적 측정값이 아니다.

## 커스텀 건물

건물 이름/주소는 표시 이름으로만 사용하며 8·12·20·30층을 선택할 수 있다. 실제 주소·평면도를 조회하거나 구조를 추정하지 않는다. 입력은 저장·전송하지 않는다. 실제 도면 가져오기·상가 전용 맵은 아직 없다.

## 검증

```sh
node --test *.test.mjs
```

41개 자동 테스트: 생존 경로·노출·제스처·달리기·성별 무관 수치·빠른 계단·VRM 메타데이터·머리/칼라 레이어 분리·장비 수집·내구도·반복 잠금 시도·실패·중단·대체 키 경로·제한 소화·사망 정리. 기존 Quaternius 예비 모델 구조 테스트도 포함한다.

Chromium 390×844 / 320×568에서 시작·전신 거울·1인칭 아래 보기·소지품·잠금 패널·작업 중단을 확인했다. VRM 12가지 조합(두 외형 × 서기/낮은 자세 × 정지/걷기/달리기)에 대해 변환값 유한성과 발 접지 위치를 브라우저에서 추가 확인했다. 실제 iPhone/Android 성능과 Safari 동작은 미검증이다.

미리보기 서비스는 Azents 인증이 필요하다. 비로그인 HTTP 요청은 401을 반환했으므로 누구나 접근 가능한 공개 배포로 간주하지 않는다. ZIP은 별도로 로컬 실행할 수 있다.
